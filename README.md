# Mejiro Lineage Legacy Website

This repository contains a polished single-page website celebrating the enduring legacy of the Mejiro lineage in the world of horse racing and breeding.

## Included
- `index.html` — the landing page structure
- `styles.css` — visual styling, layout, and colors
- `script.js` — light interaction for navigation highlighting
- `assets/favicon.svg` — custom branded favicon

## Preview locally
Open `index.html` in a browser, or serve the folder with a simple local server, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## About the design
The site uses a heritage-inspired palette, strong typography, and a modern racing aesthetic to honor the legacy of champions such as Mejiro McQueen, Mejiro Dober, and the broader Mejiro tradition.
